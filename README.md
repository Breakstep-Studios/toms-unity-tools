# Toms Unity Tools
Tools library for Unity that includes tons of helper classes &amp; methods

# Quick Start
1. Install using package manager... update this
# Requirements
* [DOTween](https://assetstore.unity.com/packages/tools/animation/dotween-hotween-v2-27676) & (DOTween Pro)[https://assetstore.unity.com/packages/tools/visual-scripting/dotween-pro-32416] must be installed.
    * Ensure that once installed the Create ASMDEF... button is pressed in the DOTWeen Uitility Panel.
